## Bloque 1 — Bienvenida e introducción (~0:00 - 0:40)

> ¡Hola! Bienvenidos a esta primera lección de nuestro curso de desarrollo web. En este curso vamos a aprender cómo se crean las páginas web desde cero, utilizando dos tecnologías fundamentales que se llaman HTML y CSS.
>
> Pero antes de comenzar a escribir código, primero necesitamos entender qué es realmente una página web y cómo funciona.
>
> Seguramente todos los días utilizas páginas web, ya sea para buscar información, ver videos, hacer tareas o simplemente entretenerte. Sin embargo, ¿alguna vez te has preguntado cómo se construyen esas páginas?
>
> Bueno, eso es precisamente lo que vamos a aprender.

---

## Bloque 2 — ¿Qué es una página web y cómo funciona Internet? (~0:40 - 1:25)

> Primero, una página web es un documento digital que podemos visualizar a través de Internet utilizando un navegador, como Google Chrome, Firefox o Microsoft Edge.
>
> Ahora bien, algo importante que debemos entender es que Internet y una página web no son exactamente lo mismo.
>
> Internet es una red que permite conectar dispositivos de diferentes partes del mundo. Por otro lado, las páginas web son contenidos a los que podemos acceder mediante esa conexión.
>
> Cuando escribimos una dirección web en nuestro navegador, este solicita información al servidor donde se encuentra la página. Después, el navegador interpreta esa información y nos muestra el resultado en pantalla.
>
> Y justamente, el proceso de crear y desarrollar estas páginas se conoce como desarrollo web.

---

## Bloque 3 — Ejemplos de páginas web que utilizamos diariamente (~1:25 - 2:15)

> Ahora que ya sabemos qué es una página web, vamos a observar algunos ejemplos que seguramente utilizamos en nuestra vida cotidiana.
>
> Primero, tenemos Wikipedia, una página que nos permite consultar información sobre diferentes temas. Si observamos su contenido, podemos encontrar títulos, párrafos, imágenes y enlaces que nos llevan a otras páginas.
>
> Por otro lado, tenemos YouTube, que seguramente muchos de nosotros conocemos. Aquí podemos buscar y reproducir videos, encontrar imágenes en miniatura y utilizar botones para interactuar con la página.
>
> Y finalmente tenemos Google, que utilizamos para realizar búsquedas y encontrar información en Internet.
>
> Como podemos observar, aunque estos sitios web tienen diferentes funciones, todos utilizan elementos como textos, imágenes, enlaces o botones.
>
> Además, cada uno tiene su propio diseño, sus colores y su manera de organizar la información. Y justamente, para construir estas páginas se utilizan tecnologías como HTML y CSS.

---

## Bloque 4 — Frontend y Backend (~2:15 - 2:45)

> Ahora, dentro del desarrollo web existen dos conceptos importantes que debemos conocer: frontend y backend.
>
> El frontend es la parte de una página web con la que podemos interactuar directamente. Por ejemplo, los botones, las imágenes, los textos y los menús que vemos en pantalla.
>
> Por otro lado, el backend es la parte que trabaja detrás de la página, procesando información y realizando operaciones que normalmente no vemos.
>
> Por ejemplo, cuando iniciamos sesión en una página, el frontend nos muestra el formulario, mientras que el backend puede encargarse de verificar nuestros datos.

---

## Bloque 5 — ¿Qué son HTML y CSS? (~2:45 - 3:45)

> Ahora que ya sabemos qué es el desarrollo web, vamos a conocer dos de sus tecnologías más importantes: HTML y CSS.
>
> Para entenderlo mejor, imaginemos que estamos construyendo una casa.
>
> Primero necesitamos crear su estructura. Es decir, colocar las paredes, las puertas, las ventanas y organizar sus diferentes espacios.
>
> Bueno, en una página web, HTML cumple una función parecida. Nos permite organizar su contenido e indicar qué elementos son títulos, párrafos, imágenes o enlaces.
>
> Pero una casa no solamente necesita una estructura. También queremos que se vea bonita, ¿verdad? Por ejemplo, podemos pintar las paredes, elegir los colores y decorar los espacios.
>
> En una página web, CSS se encarga de algo parecido. Nos permite cambiar los colores, los tamaños de las letras, los bordes y otras características visuales.
>
> Entonces, podemos recordar esta diferencia de una manera bastante sencilla: HTML organiza el contenido de nuestra página, mientras que CSS se encarga de darle estilo y mejorar su apariencia.

## Bloque 6 — Pequeña demostración de HTML y CSS (~3:45 - 4:30)

> Ahora vamos a observar un pequeño ejemplo de cómo trabajan HTML y CSS.
>
> Aquí estamos utilizando CodePen, una herramienta gratuita que nos permite escribir código directamente desde nuestro navegador.
>
> Como podemos observar, gracias a HTML tenemos un título y un párrafo que aparecen en nuestra página.
>
> Pero ahora vamos a utilizar CSS para cambiar un poco su apariencia.
>
> Fíjense cómo, al aplicar estos estilos, el fondo cambia a un color celeste, nuestro contenido se centra y el título aparece en azul.
>
> Como podemos observar, el contenido sigue siendo el mismo, pero su apariencia ha cambiado.
>
> Esto nos demuestra cómo HTML y CSS trabajan juntos. No te preocupes si todavía no comprendes todas estas instrucciones, porque las aprenderemos con mayor detalle en las siguientes lecciones.
